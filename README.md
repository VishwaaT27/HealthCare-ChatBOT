# HealthCare-ChatBOT
An intelligent healthcare assistant chatbot designed to provide basic symptom guidance, health suggestions, and user interaction through a modular Python-based architecture. Built as part of an academic mini-project with a focus on clean design, extensibility, and real-world usability.

## Features
- Symptom-based guidance
- Basic health suggestions
- Interactive console-based chatbot
- Modular and extensible design

## Tech Stack
- Python

## Project Structure
.
├── main.py
├── README.md
├── requirements.txt

## Usage
Run the application:
python main.py

## Disclaimer
This chatbot provides general guidance only and is not a substitute for professional medical advice.
